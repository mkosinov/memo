# План: #220 — колонка «Статус» (архив/активен) в таблице клиентов + унификация

## Цель

В таблице клиентов появляется колонка «Статус» с бейджем «Активен»/«Архив» (скрыта по умолчанию, включается через «Настроить колонки»); у всех архивируемых сущностей (клиенты, сотрудники, локации, услуги, материалы) колонка статуса/архива теперь скрыта по умолчанию — единое правило. Бэкенд и API не меняются.

## Архитектура

Правка целиком на уровне фронтенда, конфиг-слой DataTable (#139): колонки задаются в пер-сущностных конфигах (`clientColumns.tsx`, `staffColumns.tsx`, `materialsColumns.tsx`), видимость/персистентность/пикер предоставляет общий `DataTable` + `ColumnPicker` (`usePersistedState`, ключ `clients-columns`). Серверный whitelist сортировки клиентов не содержит `archived` — колонка создаётся несортируемой (`sortable: false`, прецедент бейдж-колонок услуг #139 §6.2). Контракт данных не меняется: `archived` уже в `ClientWithStats`.

## Стек

frontend/admin (React/Next.js, vitest + testing-library, Playwright e2e), packages/api-client (только чтение типов, без правок).

Behavioral Delta — см. спеку, здесь не дублируется.

## Task 3 — E2E клиентов: статус-колонка

Классификация: standard

**Сценарии спеки:** 1 (включение и бейджи), 2 (deep-link на архивного клиента), 3 (флип бейджа при мутации).

- Новый `frontend/admin/e2e/clients-status-column.spec.ts` (или расширение существующего clients-набора, если по структуре удобнее — без дублирования фикстур):
  1. Включение колонки через пикер → бейджи «Активен»/«Архив» у строк; без включения — таблица как раньше.
  2. Deep-link `/clients?clientId=N` на архивного клиента → строка видна; после включения колонки у неё бейдж «Архив».
  3. Колонка включена, фильтр статуса «Все» (предусловие — при «Активные» строка уходит из вида и флип не виден) → архивация клиента через меню действий меняет бейдж на «Архив» без перезагрузки; восстановление — обратно на «Активен».
- Сид: `createTestClient` из штатных факторий (параметра архивации у неё нет) + архивация сидового клиента через `POST /api/v1/clients/{id}/archive` — паттерн `client-phone-typeahead.spec.ts`.

Required Docs: [спека #220](../specs/2026-09-19-clients-status-column-220-design.md); frontend/admin/e2e/fixtures/factories.ts.
