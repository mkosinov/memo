# План: #243 — единый контракт удаления, фаза 1 (зона записи)

- Дата: 2026-09-19
- Спека: `docs/specs/2026-09-19-record-delete-error-rollback-243-design.md` (rev6)
- Канон: `docs/domain-rules/deletion.md`
- Behavioral Delta — в спеке, здесь не дублируется.

## Goal

Закрыть #243 приведением зоны записи к единому отложенному контракту удаления:
две легаси-точки мгновенного удаления (платёж и анонимный визит на странице
клиентов) переводятся на существующие отложенные варианты, мгновенные функции
удаляются как мёртвый код, восстановление после «Отменить» возвращает строку на
исходную позицию, добавлен честный текст тоста для ошибок без ответа сервера.

## Architecture

Только фронтенд. Общий пайплайн `PendingActionsContext` (окно отмены 5 секунд +
контракт ошибок D4) не расширяется, кроме одной ветки выбора текста ошибки по
типу. Кэш-помощники `recordCacheSync` получают восстановление позиции. Бэкенд,
API-клиент и ключи запросов не меняются.

## Tech Stack

TypeScript/React; TanStack Query (`setQueryData`); vitest (unit и компонентные
тесты); Playwright (e2e, перехват маршрутов).
