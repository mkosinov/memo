# План: типизация @transactional — одна обёртка без слота (#394)

## Goal

Провести ревизию 4 спеки `docs/specs/2026-10-11-transactional-typing-394-design.md` в код: убрать из обёртки `@transactional` слот-заглушку и конвенцию ведущего `None`, типизировать обёртку канонически (`P.args`/`P.kwargs`, без каста), снять 30 подавлений, валидировать контракт декоратора на момент декорирования. Поведение всех мутаций не меняется (US-1…US-5 спеки).

## Architecture

Решение и его границы — спека, секции «Контракт декоратора», «Решение (вариант C)», «Потоки отказов»: одна обёртка обслуживает обе формы (метод — инстанс приезжает первым позиционным через привязку; сценарий — чистые аргументы), сигнатура инспектируется один раз при декорировании с валидацией контракта, ядро (коммит/события #239/аудит #344) переносится дословно. Транзитивность: атомарный «флип» — переписывание обёртки ломает старые вызовы с `None` в рантайме, поэтому декоратор и вся зачистка вызовов (src + tests) садятся одним коммитом; документация конвенции (заголовки и пер-функциональные докстринги) дочищается отдельной задачей до финального греп-контроля.

## Tech Stack

Python 3.12, PEP 695/612 (`**P`, `P.args`/`P.kwargs`), mypy `>=1.13.0` strict (окружение 2.1.0), pytest; новых зависимостей нет. E2E — существующие сюиты Playwright.
