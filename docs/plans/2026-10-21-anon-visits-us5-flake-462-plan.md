# План: диагностика флейка US-5 anonymous-visits (#462)

## Цель

Выполнить спеку `docs/specs/2026-10-21-anon-visits-us5-flake-462-design.md` (рев. 2): измерить фактическую длительность сценария US-5 в CI и локально, вынести вердикт о корне флейка по критериям спеки и применить его — факт-перенос в #472 (среда) или точечная правка теста (тест). Повышение таймаутов запрещено в любой ветке.

## Архитектура

Продукт не меняется. Диагностика (задачи 1–3) работает только с данными CI (`gh` CLI: списки прогонов и логи) и локальным прогоном одного spec-файла по канон-рецепту standalone; лечение (задача 4, условная) правит только `frontend/admin/e2e/anonymous-visits.spec.ts`, используя существующий хелпер `withUndoWindow` (`frontend/admin/e2e/fixtures/helpers.ts`) по его контракту. Результаты и вердикт оформляются комментарием в issue #462.

## Тех-стек

Playwright (config `frontend/admin/playwright.config.ts`: таймаут теста 60 с, `retries: 1` только в CI, `trace: 'on-first-retry'`), GitHub Actions (`test.yml`: 4 нативных шарда, блокирующий флейк-гейт «Flake summary», артефакт `e2e-report-shard-<i>` только у упавших джобов с удержанием 7 дней), `gh` CLI для логов прогонов.

По доминантной фазе из задачи 2:

- Доминанта — окно (б) авто-коммита: перевести его на `withUndoWindow` по контракту: обёртка вызывается ДО второго клика «×»; внутри `fn` DELETE-waiter (`page.waitForResponse`) регистрируется ДО клика (не после возврата обёртки — ответ, пришедший во время drain, невидим позднему waiter); клик; после возврата обёртки — ожидание waiter и осадка ассеров (toast скрыт, перечитка, место освобождено). Порог — дефолт `advanceMs` 5_500 мс (окно 5_000 + запас). Окно (а) undo не трогается. Обязательная проверка в этой же задаче: ассерты авто-коммита и перечитки проходят на перемотке часов (риск `page.clock` + React Query не считается снятым заранее).
- Иная доминанта — точечная правка этой фазы по данным трейса; событийные ожидания сохраняются.

Запрещено: `test.slow()`/`test.setTimeout`, фиксированные паузы, рост `expect.timeout`/бюджетов конфига; правка других сценариев файла.

Проверка (сценарий 5 спеки): локальная серия `--repeat-each 3 --retries 0` зелёная; PR лечения зелёный (все шард-джобы, «Flake summary» = 0); медиана CI-длительности US-5 в прогонах после мержа ниже до-леченческой — метрика наблюдаема только после мержа, поэтому план сознательно смягчает её до наблюдения, не блокирующего закрытие. Вердикт В-тест означает, что лечение и решает задачу, — поэтому описание PR несёт `Closes #462` (в отличие от ветки В-среда, где закрытие — отдельный стоп-вопрос пользователю).
