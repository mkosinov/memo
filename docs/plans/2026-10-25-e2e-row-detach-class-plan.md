# План #535: системное лечение e2e-класса row-detach

**Goal:** структурно исключить класс e2e-флейков «снимок-потом-ассерт» —
единый примитив чтения строк `expectRowsExact`, двухуровневые конверсии 15
сайтов, канон в скилле тест-писателей, повтор move-нажатия в dayview.
Продуктовый код не трогается (0 строк).

**Architecture:** e2e-слой `frontend/admin/e2e` — общий хелпер в
`fixtures/helpers.ts`, конверсии в records/photos-crud/master-role-payments/
dayview-column-reorder спеках, канонная секция в
`.opencode/skills/vitest-playwright-patterns/SKILL.md`. Поведенческая дельта
и границы — в спеке `docs/specs/2026-10-25-e2e-row-detach-class-design.md`
(рев.2, main `eb22c534`); план не повторяет её, а разворачивает в задачи.

**Tech Stack:** TypeScript, Playwright Test (`expect.poll`, локаторные
автоповторы), существующий сид-контур (per-test `resetToSeed`, `workers: 1`).

Опорные факты для всех задач: таблица конверсий и двухуровневый контракт —
спека §Часть 1; машина состояний и проба анонсов — §Часть 3; критерий
паритета — §Тестирование.
