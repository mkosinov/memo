## 3. Компоненты главной страницы

### 3.1 Hero Block

- **Высота:** `36svh`, `min-height: 240px`, `max-height: 300px`
- **Фон:** атмосферное фото гор + градиент `rgba(0,0,0,.28) → rgba(0,0,0,.72)`
- **Header:**
  - Логотип: `sketches/Logo.png` (белый на прозрачном, само изображение — название)
  - Hamburger menu (справа)
- **Заголовок:** Playfair Display, 26px, белый, accent gold (`--gold`)
- **Pills:** «Новичкам подходит • Всё включено • Рядом с вами»

### 3.2 Календарь 

- **Формат:** "Сегодня" текстом | "Завтра" текстом | Далее виджет одна линия дней недели (Пн Вт Ср) (горизонтальная карусель дней. Первый день в карусели - завтра. Плюс еще дальше 3 дня. Итого 4 дня в карусели).
- **Стиль:** как настенный календарь
- **Текущий выбор:** красный квадрат вокруг числа (аналогично отрывному календарю)
- **Скролл:** горизонтальный, `scroll-snap-type: x mandatory`
- **Данные:** +14 дней от сегодня

### 3.3 Фильтры

**Pills:**
- «вместе» (по умолчанию) | «взрослым» | «детям»
- Горизонтальный скролл
- Активный: `--brand` bg, белый текст
- этот фильтр по возрасту не привязан напрямую к услугам, а является стэком из нескольких возрастных категорий. Логину mapping будем в следующем этапе продумывать.

**Локация:**
- Dropdown (first control)
- Приоритет: 1) cookies (последняя выбранная), 2) GPS/WiFi определение
- Если нет данных — показать все локации

- **Pills и локация должны быть в одну линию**

### 3.4 MK Carousel — Card Stack

**Паттерн:** стопка карт с вращением. Должно быть видно что под первой еще 1-2 карточки. Последней карточкой должна быть "индивидуальный мастер-класс в удобное для вас время. Материал - на ваш выбор. 8200 руб."

**Поведение:**
- Карточки наложены друг на друга с небольшим смещением и изменением размера (те что сзади - меньше. как будто немного отдалены)
- Свайп вправо/влево — следующая/предыдущая
- Тап — открыть ActivityDetail overlay

**Состав карточки (видимый):**
- Большая фотография МК (основной visual driver)
- Возрастная категория (взрослым и детям 6+/детям 6-12/взрослым и детям 12+/взрослым и детям 8+) — цветной pill. Эти категории напрямую не совпадают с фильтрами в pills.
- Название МК — Playfair Display, 18px, `--ink`
- Время и длительность
- Social proof: «Уже 3 гостя» / «Группа собирается»
- Цена: диапазон (например «3 500 – 5 500 ₽»)
- Кнопка Подробнее — `--brand` bg, белый текст

**Что НЕ показывать на карточке:**
- Преподаватель
- Длинные описания
- Технические детали
- Точное количество мест (только social proof)
- Материал: «Акрил • 30×40» это будет в деталях события.
- Локация - не надо. Это в фильтре выше уже есть и будет в деталях события.

### 3.5 ActivityDetail Overlay (3/4-экрана, slide-up)

**Триггер:** тап на карточку МК

**Содержимое:**
- Фото МК (крупное)
- Фото гостей с этим МК (если есть)
- Имя и аватарка преподавателя
- Дата и время
- Материал: «Акриловые краски, холст 30×40см на подрамнике (i)» + hint MaterialDetails
- Стоимость: диапазон +  (i) + hint PriceDetails (список всех тарифов)
- Локация + (i) + hint LocationDetails
- В следующий раз + NextTime data (3 варианта с датой+время в этой локации просто текстом, к примеру 17 мая 10:30, 18 мая 17:00). При нажатии на эти даты переход на ActivityDetail того события на которое кликнули
- Кнопка «Участвовать» → Booking Overlay

### 3.6 Booking Overlay (полноэкранный, slide-up)

**Триггер:** «Участвовать» в ActivityDetail

**Содержимое:**
- Саммари выбранного МК (фото, название, время, локация)
- Счётчики участников (зависят от имеющихся тарифов этой услуги):
  - Взрослые (от 12 лет · X ₽/чел)
  - Дети (5–11 лет · Y ₽/чел)
- Итого (динамически)
- Поля:
  - Имя
  - Телефон
  - Комментарий (опционально)
- Dropdown: «Отправить детали записи в:»
  - Telegram (по умолчанию)
  - Max
  - WhatsApp
- Кнопка «Записаться»

**Success state:**
- Иконка 🎨
- «Вы записаны!»
- Детали записи
- Кнопка «Получить напоминание в WhatsApp»

### 3.7 Отзывы (компактный блок)

- «Хорошее место 4.9★ · Посмотреть отзывы →»
- Ссылка открывает Яндекс Карты в **новой вкладке**
- Без карусели отзывов на главной

### 3.8 Галерея гостей

- Горизонтальный скролл
- Фото работ гостей
- Тег техники (акрил/масло/дети)
- По тапу — открытие фото в оверлее

### 3.9 Sticky Chat Bar

- Фиксирован снизу
- Только chips (готовые сценарии):
  - «👶 Для ребёнка 8 лет»
  - «❤️ Для двоих»
  - «🌧 Чем заняться в дождь»
  - «⏱ Есть только 1 час»
- Кнопка «Отправить»
- Без поля ввода текста

## 5. Data Flow

**Источник данных:** `@memo/api-client` → FastAPI backend

**Главная страница запрашивает:**
- `GET /api/activities?date_from=&date_to=&location=&age_tag=` — МК для карусели
- `GET /api/locations` — список студий
- `GET /api/gallery?limit=20` — фото гостей
- `GET /api/reviews/rating` — рейтинг (4.9)

**Фильтрация:**
- Календарь → фильтр по date
- Pills → фильтр по age_tag
- Локация → фильтр по location_id

## 6. Геолокация

**Приоритет:**
1. Cookies (последняя выбранная локация)
2. GPS/WiFi определение → ближайшая студия по координатам
3. Показать все (если нет данных)

**Сохранение:** при выборе локации пользователем — записать в cookies на 30 дней.

**Flow:**

- JWT токен в cookies
- Личный кабинет (`/cabinet`): предстоящие визиты + история

## 8. Технические решения

- **Next.js 14 App Router**
- **Mobile-first:** max-width 390px, centered
- **ISR:** главная страница (регенерация каждые 60 сек)
- **Images:** Next.js `<Image>`, priority для hero и первой карточки
- **Overlays:** Client Components (React state), без изменения URL
- **Analytics:** события из `main_page_spec.md`
- **LCP:** < 2.5s (priority: hero image → первая карточка → lazy load остальное)

## 13. Ключевые решения

1. **Единая дизайн-система** с админкой, адаптация: `--bg`/`--surface` как в админке, `--gold` accent, Playfair Display для заголовков
2. **Card Stack паттерн** для МК (не горизонтальный скролл, не peek-effect)
3. **Overlay-ориентированный UX** — все детали, формы, попапы — overlay, не страницы
4. **Минимум cognitive load** — одна страница, всё на одном скролле
5. **Mobile-first** — 390px max-width, все взаимодействия под палец
