## Goal

Конвенция #138 доведена до конца: **все табличные страницы админки держат фильтры (включая
пагинацию `page`/`per_page`) в URL** через общий хук `useTableUrlState`. Ссылка открывает
таблицу сразу в нужном состоянии ровно одним запросом списка; каждое взаимодействие — ровно
один шаг истории (Gate B: везде `push`); служебная коррекция вышедшей за диапазон страницы —
единственный `replace`. Сервер, контракты API и запросы не меняются.

## Behavioral Delta

Кратко (полная таблица — спека §Behavioral Delta): фильтры таблиц (все страницы) и размер
страницы живут в URL — ссылка/перезагрузка восстанавливают состояние; адрес отражает фильтры,
каждое взаимодействие — один шаг истории («назад» отменяет последнее изменение таблицы);
устаревшая ссылка с `page` за диапазоном корректируется один раз без шага истории; поле поиска
синхронно `q` из URL; закрытие deep-link-чипа клиента возвращает дефолт «активные»; период
записей теперь тоже шаг истории (`push`). Сервер и запросы не меняются (дебаунс 300 мс,
правило `q` ≥ 2 символа).
