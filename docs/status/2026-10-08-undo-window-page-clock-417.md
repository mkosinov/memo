## Goal

Каждое из 23 ожиданий истечения окна отмены в e2e спит 5,5 секунды реального времени
(~2 минуты чистого сна за полный прогон, ~114 с в shard-rest), а живое окно ещё и гонится
(#291): тест, делающий между тостом и кликом «Отменить» проверки с трёхсекундными запасами,
может опоздать за тихую границу — ложный красный при рабочем продукте. Цель — перевести окно
отмены на управляемые часы Playwright (`page.clock`): пауза до создания окна, работа внутри
без тикающего таймера, одна перемотка на 5 500 мс вместо реального ожидания. Код приложения
не меняется.

## Summary of Changes (per task)

- **T1 — хелпер `withUndoWindow` (`75827a4a`, `94357fc4`):** `frontend/admin/e2e/fixtures/helpers.ts`
  — обёртка-колбэк: `clock.pauseAt()` (в текущем реальном времени) → работа с окном в колбэке →
  `fastForward(5500)` (тихая граница) → реальный drain 500 мс в Node (коммит DeferredPromise
  TanStack + сетевые хвосты) → `resume()`. Per-page офсет фейковых часов — легальные повторные
  вызовы в одном тесте (S6: повторное создание окна после undo не ловит «clock already installed»).
  Порядок «пауза до создания окна» и неотменяемость перемотки гарантированы конструктивно
  (колбэк-форма — перемотка в самом хелпере, забыть нельзя).
