# GH #414 — Разовый аудит сохранённых логинов (User.phone)

- **Date**: 2026-10-08
- **Branch**: `414-phone-field-country-selector`
- **Issue**: #414 — телефонное поле с выбором страны
- **Spec**: `docs/specs/2026-10-07-phone-field-country-selector-414-design.md`, §«Граничные случаи и ограничения v1» (нецифровые логины, задача 10 плана)

## Что проверено

Разовая проверка сохранённых логинов перед внедрением #414: виджет входа оставляет
только цифры, поэтому аккаунт с полностью нецифровым `User.phone` войти не сможет.
Скрипт `backend/scripts/audit_user_phones.py` классифицирует каждую строку
`users.phone` по четырём корзинам:

- **OK** — сводится к цифрам, код вызова входит в кураторский список 9 стран
  (уникальные коды: 7, 375, 49, 371, 370, 48, 380, 372; зеркало словаря
  `frontend/admin/app/components/shared/phone/countries.ts`); сюда же — легаси-формы
  без кода («8 999…», «9996531803»), которые остаются рабочим ключом входа;
- **OUT_OF_LIST** — сводится к цифрам, но явно международный код вне списка («+1…»);
  вход цифрами не блокируется — информационно;
- **NOT_DIGITS** — редукция пуста (полностью нецифровой логин) — **блокер**,
  правится вручную с пользователем до приёмки;
- **EMPTY** — NULL/пусто.

Редукция — единый дом правила `to_national_digits`
(`backend/src/domain/phone_digits.py`). Подключение — только чтение (SQLite
`mode=ro`), работающие dev-серверы не затронуты.

## Где

- Локальная dev-БД: `backend/memo.db` (DATABASE_URL по умолчанию
  `sqlite+aiosqlite:///./memo.db`, cwd = `backend/`). Продакшен из окружения
  разработки недоступен.

## Результаты (локальная dev-БД, 2026-10-08)

| Корзина | Счёт |
|---|---|
| Всего пользователей | **2** (оба активны) |
| OK | 2 — `+79990000001` (admin), `+79990000002` (master), оба код +7 |
| OUT_OF_LIST | 0 |
| NOT_DIGITS | 0 |
| EMPTY | 0 |

**Вывод: нецифровых логинов нет, правка данных не требуется.** Оба значения — сид
(`backend/src/seed/seed.py`, компакт «+7…») — уже в канонической форме; правка сида
не потребовалась. Классификатор прогнан на временной БД со всеми краевыми случаями
(+375/+48, «+1…» → OUT_OF_LIST, «abc-def» → NOT_DIGITS, NULL → EMPTY, «8…», «999…»,
«+7 999…» с форматированием) — все корзины корректны, код выхода 1 при NOT_DIGITS.

## Продакшен (обязательно вручную)

Перед приёмкой #414 на проде выполнить из `backend/`:

```bash
uv run python scripts/audit_user_phones.py          # компактный отчёт
uv run python scripts/audit_user_phones.py --all    # все строки с классификацией
```

Скрипт читает настроенный `DATABASE_URL` (env/.env), открывает БД только на чтение,
код выхода 1 — сигнал NOT_DIGITS. Критерий приёмки: `NOT_DIGITS: 0`; найденные
нецифровые логины правятся вручную с пользователем (спека, §Граничные случаи).
